# Website Design Standards: From Basic ("Vibecoded") to Advanced (Bespoke)

This document serves as the strict design quality reference guide for all web development projects. It outlines what **ALMOST NEVER TO USE** (the generic AI/vibecoded clichés) and specifies how to selectively apply only what is necessary with high-end craftsmanship.

---

## 1. Core Rule: "Almost Do Not Use" Policy

> ⚠️ **STRICT DIRECTIVE**: The 30 elements listed below are generic "vibecoded" tropes. **Treat this list as ALMOST ENTIRELY FORBIDDEN.** Do NOT stack these elements together. If you must use any of them, use only 1 or 2 selectively, with extreme restraint and custom styling.

## 3. The 30 Anti-Patterns: Restricted & Forbidden List (Image 2 Reference)

### 🚫 Class A: STRICTLY FORBIDDEN (0% Tolerance - Never Use)
*These ruin a site's credibility immediately and scream low-effort AI output:*

1. **Purple and Black Theme**: Default AI dark mode (`#09090b` + `#8b5cf6` glow).
2. **Radial Orbs**: Floating blurred background circles behind every card.
3. **Rainbow Coloring**: Unrelated primary/secondary colors scattered across the page.
4. **Harsh Gradients**: Over-saturated, cheap-looking linear gradients on text or buttons.
5. **Sparkle Icons (✨)**: Placing magic sparkle emojis/icons next to every feature or button.
6. **Emojis as Feature Icons**: Using 🚀, 🔥, ⚡ in place of custom SVG icons.
7. **"It's Not X, It's Y" Copy**: Formulaic, lazy AI copywriting in hero section titles.
8. **Fake Testimonials**: Stock photo avatars with generic "This changed my business" quotes.
9. **Em Dashes (—)**: Overusing em dashes in headlines for fake dramatic effect.
10. **Terminal Window in Hero**: Generic fake code editor box slapped into the hero section.
11. **Colored Left Stripe**: 4px solid colored left border on cards/callouts.
12. **Checkmark Bullet Lists**: Generic lists of green `✓` checkmarks.
13. **Animated Bouncing Arrows**: Bouncing `->` arrows on buttons.
14. **No Terms of Service (TOS)**: Missing actual legal links in the footer.
15. **No Privacy Policy**: Missing functional privacy links.

---

### ⚠️ Class B: USE EXTREMELY SPARINGLY (Only 1-2 Allowed, Custom Styled Only)
*These can exist in a professional site, but ONLY if heavily customized and not overused:*

16. **Lucide Icons**: Avoid using out-of-the-box defaults everywhere. Custom stroke weight & inline SVGs preferred.
17. **Pure White Background**: Use soft off-whites, neutral tints (`#FBFBFB`, `#F8F9FA`), or atmospheric textures instead.
18. **Drop Shadows**: Avoid heavy, dirty box shadows. Use ultra-subtle ambient occlusion or crisp borders.
19. **3 Feature Cards in a Row**: Break up monotone 3-column layouts with asymmetric dynamic layouts.
20. **Liquid Glass / Heavy Glassmorphism**: Avoid thick blurred cards over bright background spots.
21. **Inter / Geist / Space Grotesk**: Avoid default AI font choices unless paired deliberately with a strong display font.
22. **Bento Grids**: Don't force every section into a bento grid; use grid layouts only where data warrants it.
23. **3 Pricing Tiers**: Use clear, tailored pricing tables or simple dynamic toggles instead of boilerplate cards.
24. **Soft Corner Radius**: Avoid indiscriminate `rounded-2xl` on everything. Match corner radii hierarchically.
25. **Dot Grids**: Avoid cheap CSS dot background patterns behind hero sections.
26. **Hover Animations**: Use subtle, micro-transitions (`opacity`, `transform: translateY(-2px)`), not dramatic scaling.
27. **Neon Colors**: Restrain vibrant hex codes to high-contrast focal points only.
28. **Basic Pastel Colors**: Use rich, curated HSL color palettes instead of flat pastels.
29. **No Real Product Demos**: Always show functional, real UI/interactive demos instead of static abstract shapes.
30. **No Skeleton Loaders**: Use clean skeleton loading states when real data is fetching.

---

## 4. Practical Rule of Thumb for Developers / AI Agents

- **Rule of Restraint**: When designing a page, check this list. If your proposed design uses more than **3** items from Class B (and ANY from Class A), **stop and redesign**.
- **Focus on Craft**: Prioritize real interactive product previews, bespoke typography hierarchy, rich atmospheric textures, and deliberate spatial rhythm.
